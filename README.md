# 72h — Plecak kryzysowy (BHP4ALL)

Wizualny fork [plecaka 72h](https://github.com/wonders4you/plecak-kryzysowy-72h) w kolorystyce [BHP4ALL](https://bhp4all.pl): żółty BHP `#FFCA10`, czarny `#1A1A1A`, biel.

Lokalna, interaktywna checklista na pierwsze 72 godziny kryzysu: domownicy, waga, daty ważności, ICE, scenariusze i kopia JSON. Dane zostają w przeglądarce — bez konta.
